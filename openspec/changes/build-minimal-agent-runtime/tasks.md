## 9b. 真实服务集成测试

覆盖模拟服务覆盖不到的部分：真实模型能否理解提交的工具 Schema、能否把工具结果用进回答。这些正是最先失效的地方——Schema 写得不合模型口味，工具就永远不会被调用，而模拟服务会忠实按脚本调用，测试照样全绿。

- [x] 9b.1 实现集成测试门控：凭据缺失时自动跳过（跳过不等于失败，离线全绿的前提不受影响）；支持 `AGENT_INTEGRATION` 强制启用、`AGENT_SKIP_INTEGRATION` 强制跳过、`-short` 模式跳过；验证：无凭据时 13 个集成用例全部标记 SKIP 且 `go test ./...` 整体通过
- [x] 9b.2 实现工具层真实服务测试之天气部分：Open-Meteo 免密钥链路、英文城市名、地名无法解析三条；验证：**已实跑通过**——`AGENT_INTEGRATION=1 go test -run Integration ./internal/tool/...` 返回真实数据（北京 局部多云 23.7°C、東京 25.9°C），日志中可见温度数值
- [x] 9b.3 实现工具层真实服务测试之搜索部分：博查真实检索、结果体量受配置上限约束；验证：配置 `BOCHA_API_KEY` 后 `go test -run Integration ./internal/tool/...` 中搜索用例从 SKIP 转为通过
- [x] 9b.4 实现循环层真实模型测试：工具调用链路（本地计算器与真实天气）、流式增量到达、多轮追问的指代消解、双会话隔离、待办链路、一轮内多工具定序；验证：配置模型密钥后 `go test -run Integration ./internal/agent/...` 通过
